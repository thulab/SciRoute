# GRIB 解码后渲染复用验收

2026-10-22。状态：候选实现与正确性验证完成，288 条固定查询／独立审计完成。因完整计时缺乏稳定加速依据，本轮未纳入主线，正式源码已回退。

## 候选实现与语义

- 从不可变 native Float64 场直接写最终 Float32／Float64，不生成 double 窗口中间数组；插值保留原 double 采样表达式与顺序，只在输出时转换。
- 按投影构造值与坐标轴，完整单 batch 将值数组移动到 owned 输出；分批保留整行边界及必要的最终 dtype 切片复制。消费进度依赖 domain，而非已移动数组的长度。
- 保留现有 worker 调度。完整无变换网格不产生几何键或缓存锁；实际非插值筛选按同一 native 内容条目的最近一项窗口映射复用。
- 新映射、键和管理信息纳入原 native 64 MiB 额度；替换后仍被执行持有的映射继续计费。原生场加载、逐来源费用、权限、准入、取消、持久格式和客户端请求保持原规则。

本地 88 项 GRIB 相关测试、服务器 115 项聚焦与全部 1,841 项单元测试均通过。新增 10 项 Adapter 与 6 项 Kernel 测试覆盖投影、dtype、分批／移动、映射范围、精确来源、并发替换、退役 pin、预算与取消。运行器新旧合计 29 项离线回归及独立审计工具 10 项合成回归通过。

## N8 门槛（单 campaign）

独立审计通过，72 条全部保留（60 正式＋12 预热），原服务与资源恢复通过。相对同期 A，主比较 C 的完整 R 倍数为 **1.0003**，原始完整 T 倍数为 **1.0741**，Rq 倍数为 **0.9724**。R 几乎不变，T 增加而同期 FS-index 也上移；该单轮没有证明完整查询加速。机制门槛通过，只作为进入独立 N128 三轮的条件，不作为优化收益验收，也不事后改选 B。

原始查询与资源明细留在服务器。完整 N8 独立审计 SHA：`057e1fc404e4b825b69ecf4c2b599193fa234d1887118bbf16c2862f4efdae41`；本地仅保留允许的派生摘要与原件 SHA 清单。

## N128 正式结论与主线决定

**不纳入主线，已回退本轮正式源码。** 候选确实消除了目标副本，但完整查询没有稳定加速；这不是正确性失败，也没有证明候选代码本身造成了全部时钟回退。5 个产品文件与 2 个测试文件已按预先核验的原始摘要恢复，原主线功能不受影响。候选源码、二进制、16 项新增测试与完整构建门槛仍以服务器封印快照保留；未事后更换基线、选择较快 B 或重采慢轮。

## 机制、实际资源与恢复

- 所有候选取值的真实 profile 均通过：每命中单位直接生成 4,096 个最终值；double 中间元素、未投影经纬轴、最终值复制均为 0，最终值移动为 4,096；完整网格映射查找／构建为 0，实际 B/C 开关分别为 false／true。A 没有这些新计数，其重复路径由冻结源码审查确认，不能把缺失计数解释为零工作。
- 完整独立审计通过 288 条，其中 240 正式、48 预热；N8/N128 分别 162／1,114 次周期采样、144／432 个逐查询资源帧。N128 query kernel 峰值约 124.25 MiB，DB 峰值约 11.91 GiB，没有 OOM 或配额 throttle。父组观察平均约 0.391 核的窗口包含启动、挂载、验证与采样，不是独占查询 CPU；KVM／共享存储和观测窗口限制仍在，低平均负载不能反证不存在噪声。
- 原服务与资源恢复全部通过；另做只读实机核对，最终 DataNode PID 2877245 的 250 个线程均恢复 CPU0–31 与原 cgroup，原配置 SHA 恢复为 `ddd678e310f4a48048593333bcf84b9896ab9d7d705d08c642f040723f423728`，实验 cgroup／挂载／活动进程均已清理。未增加实例、账号或许可证。

完整独立审计 SHA：`ae2713aeb3ef68557a425bdada8968253e01e11148fb94ed7c6c317f54f8de22`。本地只保留派生摘要和服务器原件 SHA 清单。首次审计误读早期 `execution-plan.json` 后停止，随后改为实际启动前已绑定的 `execution-plan-final.json`（SHA `850746…`）；原稿、拒绝日志与时间链均保留，未补写科学原件或重采查询。
